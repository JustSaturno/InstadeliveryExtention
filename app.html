Como usar (4 passos)

  1. Abra o editor de menu da loja em outra aba do Chrome. O nome da loja aparece aqui em cima.
  2. Escreva o seu pedido e clique em Copiar prompt + menu + pedido. Cole tudo numa IA (Claude ou ChatGPT).
  3. Copie o JSON que a IA devolveu e cole na caixa 2. Clique em Ver mudanças.
  4. Confira a lista, desmarque o que não quiser e clique em Aplicar. Dá para desfazer na aba Histórico.

O que dá e o que não dá para desfazer
  • Dá: voltar os campos editados (nome, preço, descrição, visibilidade etc., inclusive de grupos de complementos e opções) para o valor de antes, apagar os itens, as opções e os grupos de complementos que foram criados, e recriar opções apagadas (com um id novo) e ligar de novo complementos desligados.
  • Não dá: apagar os grupos do cardápio que foram criados, porque a plataforma não oferece isso à extensão. Isso é feito à mão no editor.
  • Não dá: trazer de volta um item que foi apagado. Por isso existe o backup (arquivo baixado antes de cada Aplicar).
  • Imagens: uma imagem trocada pode não voltar à anterior. Confira no editor.
  • Se alguém editou o mesmo item no editor depois da aplicação, desfazer vai sobrescrever essa edição.

Formato do JSON
  • A exportação é { "complement_groups": [...], "menu": [...] }. Uma lista simples de grupos também funciona.
  • Tudo que tiver "id": null é criado. Os ids existentes nunca são alterados.
  • Itens que faltam no seu JSON nunca são apagados. Apagar exige "_delete": true e a opção ligada nas Opções.
  • has_image é só informação (somente leitura). image_url deve ser um link https para um arquivo de imagem.
  • Para ligar complementos, use complement_group_ids no item (ids, ou o nome de um grupo criado no mesmo JSON).
  • Itens com complementos podem ser editados normalmente. O editor os envia como qualquer outro item.
  • "A partir de": "from_price": 20 no item mostra "A partir de R$ 20" no cardápio (útil quando o preço depende do tamanho). null remove.
  • Campos extras do item: strike_price (preço riscado), is_alcohol (+18), is_highlight, is_best_seller, is_newest (0 ou 1), minimum_quantity, internal_id e days ("all" ou uma lista como ["fri","sat"]).
  • Banco de imagens: itens sem imagem (e itens novos) recebem automaticamente a foto parecida do banco da plataforma. Um image_url enviado pela IA sempre vence. Use "image_url": null para um item NÃO receber foto do banco, e "image_query": "refrigerante lata" para dar uma dica de busca. Tudo isso também vale para grupos (banners).

Problemas comuns
  • Erro 401 / "Sem token": o token expirou. Recarregue a aba do editor (F5), espere carregar e tente de novo. Ele também é apagado sempre que você recarrega a extensão.
  • Pílula da loja vazia: recarregue o editor na página do menu, para a extensão ver a requisição do menu.
  • Imagem ignorada: o link não é um arquivo de imagem direto, o site bloqueia downloads, ou o arquivo é grande demais ou está quebrado.
  • Parou no meio do Aplicar: veja o erro no registro, clique em Exportar e depois em Ver mudanças. Só o que faltou aparece. Atenção: itens NOVOS que já foram criados teriam de ser removidos do JSON, senão são criados de novo (a extensão avisa quando o nome já existe).
  • Aviso de loja errada: a aba do editor carregou por último uma loja diferente da sua exportação. Exporte de novo da loja certa.
